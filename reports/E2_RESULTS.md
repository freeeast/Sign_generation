# E2 · 真人姿态上的反馈可靠性

用 Uni-Sign 作者归档中的 How2Sign test RTMPose 关键点执行。按归档索引 0、71、142、213、284、355、426、497 系统抽取 8 个片段，来自 7 个源视频 ID。另用 1 个作者预测曾与标签完全一致的片段作为正对照，排除于 8 段的汇总。每段执行 12 个几何或分数条件，加 1 个来自不同源视频、动作帧数尽可能接近、文本不同的错配动作，共输出 117 行明细，其中 pilot 104 行。

比较扰动前后同一句参考文本的逐 token NLL。ΔNLL 为扰动后减原始序列，越高表示同一句话对模型来说越不可能。正向计数用 ΔNLL > 0.0001。投影不变性对照为坐标的统一缩放和平移。手指噪声级别按归一化坐标中的肩宽定义，剂量之间复用同一组随机噪声方向。

| 条件 | ΔNLL 中位数 | ΔNLL 上升 |
|---|---:|---:|
| 错配动作 | +1.70 | 8/8 |
| 静止姿态 | +1.55 | 8/8 |
| 冻结手型 | +0.95 | 8/8 |
| 时间倒放 | +0.93 | 8/8 |
| 打乱帧序 | +0.89 | 8/8 |
| 20% / 10% 肩宽手指噪声 | +0.84 / +0.48 | 6/8 / 6/8 |
| 5% / 2.5% 肩宽手指噪声 | −0.04 / −0.03 | 3/8 / 3/8 |
| 仅把可见点分数设为 1 | +0.04 | 7/8 |
| 等比缩放加平移 | < 0.000002（最大绝对值） | 0/8 |

图见 [反馈分布](../experiments/E2/feedback.png)，逐条原始值见 [CSV](../experiments/E2/per_clip.csv)。手指剂量增加时，中位编码余弦相似度由约 0.98 降至 0.28。该相似度会受到几何扰动影响，能否衡量语义需用跨域配对数据确认。

**证据边界。** 这是小样本诊断。一个 5 帧片段在重度坐标噪声下反而提高目标句概率。冻结手型同时冻结手腕相对的手指方向，且参考帧有缺失时改变手指 mask。错配动作可能保留签者、风格、内容或时长差异的混杂。下一轮引入同签者、同主题、相似时长的错配。整个实验使用归档的真人侧关键点，向 3D 虚拟动作的迁移仍待验证。
