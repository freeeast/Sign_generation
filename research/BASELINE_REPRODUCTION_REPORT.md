# 基线复现

- SignSparK 官方 commit 与 Hub 快照已记录，原命令在启动依赖处失败，四种模式的实测状态和配置查证见 [官方复现记录](baselines/SIGNSPARK_REPRODUCTION.md)。官方权重产生的动作未纳入比较。
- 历史 5,000 步 DDPM clean+velocity 权重成功复取并重新采样 32 个种子。它是同表征但不同训练预算的外部参照。32/32 未触发高频阈值，双手速度更接近 NSA，但相似参考模式的覆盖不足。
- Flow 小样本用两个训练窗和两个验证窗完成 300 步，训练损失由初次报告的 1.9447 降至 1.3153。能采样并导出合法轴角，有限预算下属于拟合检查，不能作为自然度证据。
- Flow 白噪声基线按 421/59 录像源、2,500 步、100 次 Euler 调用与 96 帧学习；验证 MSE 1.4908 → 1.2367。32 段完整生成和坏例保存于实验包。源、完整运行摘要和 checkpoints 见 [复现指南](REPRODUCTION_GUIDE.md)。
