# 假设记录

## H01 · 流模型匹配时间相关噪声

- **观察**：E0 的 32/32 个 4 秒生成窗超过验证参考尾部的抖动阈值。每段双手步长 P95 的中位数为 50.92° / 55.91°，参考为 20.24° / 31.98°。8 个 FK 样本的腕相对指尖速度中位数超过 2 m/s。最严重右手样本包括 42、28、29。
- **可疑机制**：独立逐帧高斯源对 24 Hz 动作引入较强高频变化。有限容量和预算下，模型需要同时消除逐帧噪声并学习人体动作。过多步长也可能来自 Euler 误差，单独用 E0 权重加倍求解步数排查。本实验无法排除其他原因。
- **机制**：沿时间轴将白高斯转为平稳 AR(1) 高斯，固定 rho=0.85。每个时点单变量方差仍为 1，关节特征间的噪声保持独立。训练匹配与推理使用相同变换。入口仍为标准白 Gaussian seed。参考动机为连续路径 Flow Matching，具体变换取线性可逆白噪声变换。
- **隔离**：E0 已冻结。E1 只启用相关噪声，E2 在新实现将 rho 设为 0，验证输出与 E0 一致。使用相同架构、421/59 源、2,500 步、种子 455、100 次模型采样调用、96 帧。E3 用第二训练种子及同组 32 个推理种子，计划检查选定版本在官方 test。
- **证伪**：双手逐样本 P95 的平均值相对 E0 至少降低 20%，两手分别向参考移动，且每只手的样本间平均角距离至少为参考的 80%。最终还核对覆盖和腕相对指尖活动，不因 P95 降低单独判定自然性。成功标准仅限抖动缓解。
- **成本**：同 CPU 主跑预算，两组基础训练 + 两组第二种子，单组约 1–2 分钟。决定 Test。

## 延后

1. 双手腕速度同步偏低。单次 FK 子集太小，先核对两种子和更多参考。
2. 伪标签中的快速角跳变。记录频率，未定位真实手形质差或实际穿插。DexAvatar 约束和 VideoMDM 2D 辅助待输入对齐与独立观测证据后再试。

## H02 · 同一机制的更强相关性

E1 抑制极端抖动后，左/右手角速度中位数仍为参考的 4.38/2.20 倍，3 近邻 precision 代理由 0.531 降到 0.219。测试将同一 rho 从 0.85 提高至 0.95 是否减小速度偏差并改善覆盖权衡。其余条件不变，只使用 val。保留加强版需两手中位速度均更接近参考、精度代理不低于 0.219、双手差异至少为参考的 80%。本轮锁定 test 结论仍只针对 E0/E1。新增 2,500 步的一次 CPU 训练。

**结论**：H01 的抖动缓解在两个训练种子得到支持，整体自然度不成立，粗精度下降。H02 完成单种子验证，达到预定义门槛，未驱动新的测试集选择。同步偏低和较小高频尾部保留为剩余失败。详见 [迭代一](../reports/ITERATION_01.md) 与 [迭代二](../reports/ITERATION_02.md)。
