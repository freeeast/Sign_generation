# 实验记录

Git 起点 596d6e9。授权数据缓存与模型记录见 [数据清单](datasets/DATASET_AUDIT.md)及 [结果快照](evaluations/results/experiments.json)。每个训练 checkpoint 记录实际代码 SHA、种子和配置。公开提交保存实验最终实现，冻结 E0 与 E2 已验证相等。

| 阶段 | 实施与实测 | 决策与续跑 |
| --- | --- | --- |
| 外部基线 | 核对官方实现与三个真实权重大小。尝试官方命令，缺 Hydra 等前置包。无可用 CUDA 或全流磁盘容量。 | A–D 官方生成阻塞，保留 launcher 和版本。 |
| 已有基线 | 5,000 步 DDPM 加载已发布项目权重，采样 32 段。有低多样性、欠覆盖。 | 保留作为不同预算的参考。 |
| Tiny | 2 个 48 帧训练窗与 2 个验证窗，300 步，训练损失下降，生成的 2 秒样本做 FK 和 MP4。 | 工程 sanity 通过。 |
| E0 | 421/59 个源、2,500 步约70秒、种子455、100 NFE。32/32 抖动超阈。 | 冻结对照。 |
| 数值诊断 | 相同权重 200 NFE，32/32。 | Euler 加倍不能解决。 |
| E1/E2 | rho=.85 在 2,500 步约81秒，改善抖动；rho=0约79秒，完全复现实测权重和样本。 | 支持抖动缓解。 |
| E3 | 种子733，两臂各2,500步约89秒；复现同样抖动收益及较低精度代理。测试窗只比较冻结的种子455权重。 | 保留 rho=.85 为可复验候选。 |
| I02 | rho=.95、同预算91秒，降低中位速度偏差，精度代理部分回升。 | 仅验证集单种子，未锁定新模型。 |

产物放在 `work/loop/<run>/` 和实验下载包的 `runs/<run>/`。最重单模型 checkpoint 约 3.7 MB，历史 DDPM 约 7.2 MB。CPU 运行，GPU 峰值内存不适用。完整回放见 [复现](REPRODUCTION_GUIDE.md)。
