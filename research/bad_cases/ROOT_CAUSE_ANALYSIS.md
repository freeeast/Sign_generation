# 假因与实测排查

1. **旋转表示**：两手沿用 43 关节轴角→SMPL-X 手均值→SO(3)→列式 rot6d→轴角。样本矩阵正交和行列式误差约 1e-7，FK 有限并可视化。数值有效无法保证生理手形、腕手同步或接触。
2. **数值积分**：E0 同权重同种子将 100 次 Euler 调用改为 200 次，抖动超阈仍为 32/32。双手角度 P95 中位数 50.92/55.91° 与 50.85/55.94° 接近。这个步长区间不是观察到的主要速度偏差来源。
3. **学习过程**：改变训练及采样的噪声时间协方差，其余设置匹配，显著降低高频转角。把相关设为零后，重新训练得同样模型张量且三段生成文件逐数组一致。说明该设置能控制本实验的抖动度，但不区分训练期和采样期各自作用。
4. **参考与评价**：伪标签也含急转，FK 指尖近似受局部关节误差影响。覆盖代理只看 8 个时点，在 32 段上的 precision 可能有波动，不能视为 FID 或真实数据的自然度。请结合邻域、手指、腕部指标和定点播放。
