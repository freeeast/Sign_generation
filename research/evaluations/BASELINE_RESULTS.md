# Baselines 与迭代结果

同一 24 Hz、96 帧协议。每模型 32 个生成种子，对照为 32 个留出验证窗。每段 P95 为全部手关节帧间转角的分位数，再对段取中位数。P/R 为 8 时点 rot6d 上的 3 邻域代理。

| --- | ---: | ---: | ---: | ---: | ---: |
| NSA 验证参考 | 20.24 / 31.98 | 5/32 | 55.28 / 121.49 | 29.83 / 32.31 | — |
| 历史 DDPM | 8.70 / 16.27 | 0/32 | 69.47 / 118.46 | 21.20 / 23.85 | 1.000 / 0.000 |
| E0 白噪声 Flow | 50.92 / 55.91 | 32/32 | 536.30 / 574.80 | 33.01 / 35.26 | .531 / .781 |
| E1 rho=.85 | 25.44 / 30.21 | 0/32 | 242.31 / 267.27 | 33.76 / 36.20 | .219 / 1.000 |

E2 rho=0 的网络所有张量以及三次采样导出的所有数组等于 E0。历史 DDPM 使用更宽模型、双倍训练步数和不同训练目标。不能对扩散和 Flow 作因果排序。

官方 test 只用于已锁定 E0/E1，二者使用同一 32 个生成窗，与另 32 个测试录像窗对比。按测试参考阈值依然为 32/32 和 0/32。P/R 代理由 .188/.813 变为 .094/.969，说明自然度的质量取舍在测试参考下仍存在。一致候选的最近训练窗粗描述均无精确匹配，E0/E1 中位 RMSE .245/.248，参考验证 .224。粗近邻不能排除更近的时移或局部手形复用。
