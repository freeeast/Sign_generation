# 研究决策

1. 主基线采用时域卷积去噪器的无条件 DDPM，噪声和时步驱动整个 96 帧窗口。余弦噪声表和高斯后验来自公开 DDPM 方法，采用仓库已有的双手 SMPL-X 接口。先检查噪声目标与 clean-pose 与速度匹配的复合目标。后者只约束 rot6d 的一阶差分。
2. 若直接扩散持续出现跳变，下一轮候选是同表征的 rectified flow。保持官方划分、归一化、导出、样本数和评价协议，改用高斯到真实轨迹的速度场。优先验证跨时与手部动态，再考虑专用手分支或 latent bottleneck。
3. 同时报告抖动和过平滑，保留两个方向的失败。以验证集确定模型。测试集仅用于预先锁定的配置与对照。GRU/Hold 在相同的 12 Hz 指标下评估，另保留生成样本和 NSA 的原生 24 Hz 对照。
4. 生成器负责 43 个局部关节。中性体型、固定根和中性非活跃关节提供一致的 FK 脚手架。面部、全身位移、真实接触与语言可懂性需要独立的后续验证。
