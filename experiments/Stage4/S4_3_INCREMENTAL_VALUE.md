# S4.3 · 几何之外的价值

**近并列候选的跨检测器几何排序有局部收益，独立语义收益仍待盲评。**

## 设计

每个序列每类手指、腕朝向、手臂变形固定一个 16° 损坏，从同一损坏构造七个 8° 修正方向。比较全部两两组合，得 **315 个**基础候选对。另有 30 行受控条件。腕相对指尖用于手指与腕朝向，全图指尖用于手臂。用 RTMW 奇数帧 A 折（1 mod 4）限制起始误差差值，用 MediaPipe B 折（3 mod 4）误差的符号作为几何判定。要求 B 折至少 8 帧可见以及误差差值超过 0.2 px。可见手由固定 RTMW 腕锚辅助分配。全部候选都是同一原动作的人工扰动。Neural Sign Actors 的原拟合流程也使用过 MediaPipe 关节。这里的观测独立于 Uni-Sign 和 RTMW 的分值，但可能与原拟合共享检测器偏差。[NSA 拟合方法](https://guanxiongsun.github.io/projects/neural-sign-actors/#data-a-3d-version-of-how2sign)

炸薯条、上色用于按信号估计原始差值的绝对中位尺度。踢拳、篮球、诊断用于验证，三个来源均已在上一轮 pilot 中出现。具体组合是几何差除以近并列阈值，再加按校准尺度除、限制在 ±1 的反馈差，权重固定 0.5。各信号全部报告。组合与独立检测器对齐的结果只反映 2D 几何候选选择。

| 方法 | 1.0 px 近并列，48 对 | 0.5 px 近并列，27 对 | 1.0 px 阈值下，相对几何的逐源等权增益 |
|---|---:|---:|---:|
| 几何 | 33/48 | 16/27 | — |
| 几何 + 句子 NLL | 38/48 | 18/27 | +11.5 pp |
| 几何 + 全局编码 | 36/48 | 20/27 | +8.0 pp |
| 几何 + 逐帧编码 | 37/48 | 20/27 | +9.8 pp |
| 几何 + 手部空间 | 34/48 | 18/27 | +4.8 pp |
| 几何 + 手部时序 | 37/48 | 20/27 | +11.5 pp |

48 对由 30 个手指、12 个腕朝向、6 个手臂对组成，来自 3 个来源，同一来源共享候选。按来源重抽样的描述性 95% 区间，手部时序为 −2.2 至 +25.7 pp，逐帧为 −1.1 至 +18.9 pp。仅 3 个来源，区间只提示不稳定性。手部时序在踢拳、篮球、诊断分别命中 15/20、14/18、8/10，几何则为 13/20、15/18、5/10。

**结论对标注边际敏感。** 保持起始 1.0 px 门槛，MediaPipe 标签差须 >0.5 px 时，几何 28/37，逐帧 31/37，手部时序 30/37。将标签差门槛提高到 >1.0 px 后，几何、逐帧、手部时序与 NLL 都是 **14/15**。NLL 与几何联合的收益可以和它在已知恢复方向上频繁逆序同时成立，两项比较的候选和目标不同。
