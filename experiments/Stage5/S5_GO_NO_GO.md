# S5 · CONDITIONAL GO

**值得继续小规模验证每段动作修复。目前维持大规模 E4 的 NO-GO。**

1. **技术可行。** 三段中主闭环的手部时序响应距离都下降。实际改动涉及双手手指、腕朝向及臂轨迹的六个时序系数。
2. **动作质量与目标能分离。** 主方法相对同一扰动起点改善了三段留出几何。仅优化时序距离虽然有更低专家损失，却在三个来源都损失腕点位置精度。
3. **几何之外的证据有限。** 主方法相对等预算几何，踢拳改善 0.57 px，诊断恶化 0.53 px。全局和手部空间作为次要对照在这两个来源上方向更一致，现有样本仍不足以选定最终反馈。
4. **语言收益未建立。** 只有独立于目标的 2D 检测对照。缺人工语义评审、真实 3D 真值和未参与之前诊断的新来源。

本轮只支持 A 路线的每段独立闭环优化机制。共享动作控制器和条件 3D 生成需要额外的泛化与语义证据。训练、强化学习和全 RGB 渲染均未启动。
