# 下一步 · 从单段闭环到可复用动作

1. **先确认 A 路线的增益。** 保留当前 3D 参数更新、固定相机和等预算几何对照，从新来源取 4–6 段具有明确腕或手型差别的片段。预先冻结权重、候选空间和判定阈值，并确认全局编码在这两个片段的次要结果能否复现，同时保留主手部时序作为对照。按来源留出，分别报告 2D、动作合理性、手语语义。用多人 ASL 盲评比较 B 与 C 的动态输出。
2. **做老师提出的同一 RGB 管线小对照。** 取得授权 SMPL-X 网格资产及原视频相机或验证过的裁剪映射，以相同帧率、视角、裁剪规则和手部像素尺度渲染短序列。真实与虚拟画面都经同一检测器。若要加入 RGB 手部支路，需要同一个支持 RGB 的冻结权重、原协议的手部裁剪和时序输入。先复核手/脸可见性、遮挡和置信通道的域差，再比较识别响应。Stage 5 的关键点闭环没有测这个像素域。
3. **在独立证据过关后考虑 B 路线。** 多来源的纠错轨迹至少要含可信的改进和失败标记，才适合学习共享校正器并测未见来源。C 路线还需要文本或 gloss 对齐的动作建模、持续时长/共发音与非手部信号的评价。本阶段保留 A 路线的每段独立优化，B 和 C 均未实现。
