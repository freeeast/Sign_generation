# S5 · 优化轨迹

**闭环能更新真实 SMPL-X 参数并降低虚实专家距离。** 预设主方法 C 时序从同一个扰动起点出发，在三段分别接受 6、7、7 次更新。每个更新用新的 SMPL-X 参数重新 FK、投影并送进冻结的 Uni-Sign。36 个提案覆盖三个逐步减小的坐标步长。提案表含被拒绝的候选和其约束状态。

| 片段 | 手部时序距离，I → C | MediaPipe 奇数帧综合误差，I → C | C 接受步数 |
|---|---:|---:|---:|
| 上色（校准） | 0.12042 → 0.11243 | 12.85 → 10.85 px | 6/18 |
| 踢拳（留出） | 0.12968 → 0.12606 | 16.07 → 13.41 px | 7/18 |
| 诊断（留出） | 0.16648 → 0.15436 | 22.88 → 17.47 px | 7/18 |

无几何项的 D 也在三段实际更新了参数，并让手部时序距离低于相同片段的 C。几何误差从起点改善 2/3，且 D 的腕点误差在三段都升高。几何守护项对只追求响应一致的闭环有实际作用。

三段的 C 在最终状态相对公共起点均降低了到原拟合的 3D 腕点与手部中位误差。这个量测量恢复到拟合的程度，不是相对真人的 3D 真值。C 的 3D 手部加速度 P95 相对起点分别变化 −1.03、−2.43、−0.88 mm/帧²。绝对体态、接触、动力学与独立语言指标尚未测量。

每段目录含优化中每步的目标、专家距离、几何/运动学评估、所有试探系数及最终 SMPL-X 参数。动画同时显示正投影和 3D 骨架侧视。可用 [比较数据](comparison.csv) 和 [目录中的复现命令](S5_CLOSED_LOOP_IMPLEMENTATION.md) 复核。

## 约束、评估帧和预算审计

三个来源的六条搜索臂共记录 **648** 次逻辑提案、**180** 次接受更新。全部提案通过本轮相对限幅。各方法端点的最大附加旋转 **19.29°**、速度 **0.652°/帧**、加速度 **0.044°/帧²**，分别低于配置的 20°、2°/帧、0.5°/帧²。相对原拟合的骨段长度漂移 P95 在各端点中最高 **0.636 mm**。固定臂外的参数保持一致。

使用保存端点对奇数帧再次提取同一冻结专家，主方法的手部时序距离从起点在 3/3 下降。踢拳和诊断的 C 距离也低于 B（**0.14755 vs 0.14854**、**0.14780 vs 0.14970**）。奇数帧未直接进入损失，但与偶数帧时间相邻。这个检查说明对齐保持到相邻帧。独立语义评价仍缺。
