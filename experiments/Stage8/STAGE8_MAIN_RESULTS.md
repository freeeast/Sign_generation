# Stage 8 · 虚拟人反馈模仿实测

**在粗拟合初态，分阶段闭环在 3/3 段降低了最终双手专家距离，平均仅 0.89%。** 用独立左右手局部控制扩大专家阶段的步长后，两个长片的响应降幅提高到 2.12% 和 3.29%，三个来源的留出正面几何都较各自初态改善。结果支持受限的逐段模仿能力，粗拟合到高质量签语动作之间还存在明显差距。

## 数据和初态

使用 Stage 7 已有的三个不同 How2Sign 源录像，共 479 帧，24 fps。按配置固定最短的三个可用源，均已有 Neural Sign Actors 拟合、同帧 2D 观测和代理相机。这些录像跨源独立，本轮复用旧样本，未将其当作完全未接触的外部数据。所有初态的体型系数在一段内固定为该段的中位数。各方法共享同档初态、观测、预算和约束。

| 源录像 | 帧数 | A 原拟合姿态 | B 从观测重新粗拟合 | C 合成挑战 |
| --- | ---: | ---: | ---: | ---: |
| `33jxeIIbBnM_21-1-rgb_front` | 49 | 0.11388 | 0.14906 | 0.20232 |
| `3sZjSNcqXpI_2-1-rgb_front` | 212 | 0.06710 | 0.27930 | 0.11113 |
| `ETOZLBScxWY_12-5-rgb_front` | 218 | 0.09087 | 0.31423 | 0.12134 |

表为初始专家响应距离。B 只从真实偶数帧的 2D 肩、肘、腕及掌骨指节点做稀疏样条控制的 3D 逆运动学，手指为 SMPL-X 平均手型。原拟合的根、躯干、面部及代理相机作为上下文复用，未复用臂、腕、手指旋转。C 从 A 施加 14–18° 平滑偏差及最多 8° 的离轴分量，部分扰动可由已有控制轴表达，单列为恢复压力测试。

## 粗拟合主对照

各臂固定 18 次坐标决策、36 个提案。表为实际 3D 动作生成的直接虚实专家距离，从公共初态到终点。每对方法的留出几何只用于评价。

| 方法 | 33jxe | 3sZj | ETOZ | 平均相对降幅 |
| --- | ---: | ---: | ---: | ---: |
| A 纯几何 | 0.14906 → 0.16044 | 0.27930 → 0.27759 | 0.31423 → 0.31445 | −2.36% |
| B 仅专家 | 0.14906 → 0.14308 | 0.27930 → 0.27710 | 0.31423 → 0.30676 | +2.39% |
| **C 先几何、后专家** | **0.14906 → 0.14876** | **0.27930 → 0.27673** | **0.31423 → 0.30937** | **+0.89%** |
| D 联合目标 | 0.14906 → 0.14361 | 0.27930 → 0.27655 | 0.31423 → 0.31153 | +1.83% |
| C2 局部手指 | 0.14906 → 0.15031 | 0.27930 → 0.27537 | 0.31423 → 0.30749 | +0.91% |
| C3 局部手指、大步长 | 0.14906 → 0.14932 | 0.27930 → 0.27337 | 0.31423 → 0.30388 | +1.75% |

C 的专家阶段每段实际接受 7 次更新。三个真实序列的 0/6/12/18 步轨迹为：

- 33jxe：**0.14906 → 0.16088 → 0.15374 → 0.14876**。先几何阶段偏离专家响应，随后追回；留出误差 **17.38 → 16.53 px**。
- 3sZj：**0.27930 → 0.27816 → 0.27721 → 0.27673**。留出误差 **25.51 → 25.76 px**，几何微退。C3 后为 **24.62 px**。
- ETOZ：**0.31423 → 0.31392 → 0.31047 → 0.30937**。留出误差 **29.36 → 29.59 px**。C3 为 **28.16 px**。

C、D 和 C3 终点的专家距离均比纯几何低，说明几何和专家提供不同控制信号。C 的留出正面几何比纯几何只在 1/3 段更好，另两段分别高 0.10 和 1.57 px。C3 在两个来源胜过纯几何正面几何，第三段高 0.14 px。仅专家在三段都降分，却使三段留出几何较初态分别恶化 **0.40、0.78、0.97 px**。D 在 B 档比 C 的平均专家降幅大，但两者逐源各有胜负。没有稳定的总体优胜者。

## 三档初态与约束

| 初态 | C 的平均相对降幅 | C 是否低于初态 | C 的留出几何与初态 |
| --- | ---: | ---: | --- |
| A 原拟合姿态 | −1.55% | 0/3 | 3/3 改善 |
| B 粗拟合 | +0.89% | 3/3 | 1 段改善、2 段略差 |
| C 合成挑战 | +20.25% | 3/3 | 3/3 改善 |

合成档纯几何也降 15.33%。由于挑战的部分旋转可由原控制轴表达，不能把合成恢复外推到真实粗拟合。A 档 C 从几何锚点进一步下降，但相对共同初态没有转正。

四种主臂和两种定向改进共 **42 条完整轨迹、1512 个提案**。42 个终点无增量约束和新增转角包络违规，最大增量转角、速度、加速度分别 **19.60°、1.66°/帧、0.230°/帧²**。上臂和前臂段长在各阶段的最大数值变化低于 **0.001 mm**。这些检查支持有限运动可行性，接触、碰撞、手语正确性未由其验证。

## RGB 和留出评价

对短片和第一段长片重新运行真视频 RTMW，把初态、纯几何和 C 第 6、12、18 步等渲染到同视角，使用相同检测器、图编码和时间索引。13/18 个输入帧，在所有测试候选上保留 100% 的合格真实手部支持。主 RGB 结果：

| 来源 | RGB 初态 | RGB 几何终点 | RGB C 第 6 → 12 → 18 步 | RGB C3 终点 |
| --- | ---: | ---: | ---: | ---: |
| 33jxe | 0.09948 | 0.08804 | 0.09550 → 0.09821 → **0.08679** | 0.08931 |
| 3sZj | 0.24841 | 0.24488 | 0.24445 → 0.24409 → **0.24331** | 0.24084 |

C 的 RGB 终点在两段低于初态和纯几何，胜过后者的幅度分别约 0.00125、0.00157。短片的中间分数反弹，C3 对纯几何也没有 RGB 优势。按几何门限对实际 C 检查点进行 RGB 重排，两段都选第 18 步。主流程仍固定取第 18 步。阶段 7 同网格改材质曾改变约 0.008 的手部时序距离；此为不同口径和来源的扰动量级参考，无法当作本阶段的统计门限。

侧视可用一段，3sZj 的 163 个奇数帧可关联手实例，沿用 Stage 7 的代理侧相机。粗拟合初态的侧视综合 64.24 px，纯几何 65.18，C 64.42，C3 64.21。侧视绝对残差较大且相机近似，不能确认三维准确性。额外的留出全局特征和原句 NLL 来自同一 Uni-Sign 权重，见 `secondary_expert.csv`。C3 的全局距离在 33jxe、3sZj 下降，在 ETOZ 略升。
