# Stage 8 · 判定

**CONDITIONAL GO。继续同一虚拟人模仿闭环；当前证据支持每段有限修正。**

| 问题 | 本阶段判断 |
| --- | --- |
| 虚拟人能否逐步模仿 | 可以在固定动作空间内反复更新参数，使粗拟合的冻结专家响应逐步接近。原 C 的专家相位三段均接受 7 次实际更新。表现受初态和控制参数化限制。 |
| 哪档初态可用 | A 原拟合已经接近，C 全流程未降终点。B 三段有小幅响应收益，局部手指放宽步长后两个长片提高明显。C 合成挑战可以恢复，证据不外推到任意输入。 |
| 专家信号有无超出几何的信息 | 有。C 在所有粗拟合源最终专家距离优于纯几何。仅专家常带来点位漂移，几何增益仍不稳定。 |
| 是否保持运动可行性 | 42 个终点满足测得的增量边界、固定体型及上臂/前臂段长要求。没有人体接触或碰撞真值。 |
| RGB 是否能保留改善 | 两个 B 源的 C 终点低于各自初态及纯几何，部分中间结果不保留直接排序。C3 的 RGB 增益只在一个源超过纯几何。 |
| 是否达到可复用水平 | 已有带接受/拒绝、动作参数与专家响应的训练候选记录。三个录像复用且新局部臂为事后定向验证，没有足够证据用这些样本训练后声称跨源泛化。 |

核心结论是可运行的弱监督 3D 模仿实验。专家对齐并非 ASL 语义准确性证据，当前粗拟合与原拟合间的差距仍大。
