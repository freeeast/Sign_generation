# S6 同一 RGB 姿态管线

## 从像素到专家闭环

实际运行 SMPL-X 参数 → FK/Mesh → 正面 RGB → YOLOX tiny/RTMW → Uni-Sign → 候选搜索 → 更新 SMPL-X。网格有 10,475 顶点及 20,908 三角面，Mesa EGL 投影、深度遮挡及简单材质。两个配对源均以 1280×720、24 fps、原帧索引输出。位置沿用固定的 OSX 内参假设和上身代理裁剪。没有独立逐帧 crop，服装、身体形状、背景和面部造型仍有差异。真人与虚拟共用同一 RTMW 实例、同样的 BGR 输入、133 点选择和 Uni-Sign 预处理。搜索时直接检测渲染缓冲区，视频是同一帧的 H.264 记录。RGB 用原始检测分数，保留缺失坐标和分数。这是 RGB 经姿态专家的闭环，检查点的专家输入为关键点。

用检测分数判断时，两段真人及主渲染的身体检出率、双手合格比例均为 100%。3xni 真人左/右手分数中位数 0.653/0.798，渲染 0.853/0.838。进一步加画面内要求后，3xni 真人左/右手合格帧比例只有 50.8%/54.1%，有 45.7%/42.1% 手部点同时满足高分和越界。渲染越界点比例为 5.8%/1.9%。拳击真人左手合格率 94.6%，右手 100%。这显著改变了对只有分数门限的可见性判断。这里合格定义为每手 21 点中至少 11 点超过 0.3，画面内审计使用归一化坐标 [0,1]²。新源直接投影的中指 MCP–腕像素距离左右中位数约 69.7/65.5，真人 RTMW 为 40.4/49.4，两侧投影尺度仍有差异，后者含画面外预测。

同一动作和网格上，仅变更材质能使时序距离增加 0.00474、全局距离下降 0.01041。两项对材质变更的响应方向相反。真实衣料肤色、遮挡、形体差异和分数都可能参与。没有用专家分数标定相机。

## 真实 B3 迭代及几何对照

3xni 用 21 个固定输入帧，8 Hz 专家输入，原电影和评估在 24 fps 栅格上。候选各用手指、腕和臂第一时间窗一轴，半径 6°，共 3 次决策 / 6 个提案。以同一初态、同一固定相机和原几何锚，比较仅几何、直接反馈与 RGB 反馈。质量使用其余 20 个奇数帧的 MediaPipe。黄金动作无独立人工标注。

| 同一完整短序列 | 新增专家路径使用的时序距离终点 | 统一经 RGB 重评的时序距离 | 留出综合 px |
| --- | ---: | ---: | ---: |
| 扰动初态 | — | 0.08124 | 14.755 |
| 几何 | 无反馈 | 0.08442 | **13.927** |
| 几何 + 直接投影 | 0.13559 | 0.08442 | **13.927** |
| 几何 + RGB | 0.07971 | **0.07971** | 14.556 |

RGB 接受 2 个更新，直接投影接受 3 个，均符合设定修正边界。RGB 时序距离变化 **0.08124 → 0.07971**，留出像素误差 **14.755 → 14.556**，较纯几何高 **0.629 px**。RGB 第一步时序一度达 0.07875，第二步以更好的几何改善联合目标，使时序回升至 0.07971。全长的纯几何和直接反馈输出参数一致。对同一 RGB 终点仅把分数强制设为 1 的事后诊断，时序距离从 0.07971 变为 0.14106。以投影姿态对同一网格的 RTMW 输出进行比较，四个端点腕相对手型偏差约 18.83–19.66 px。同一检测器把表示拉近的一部分来自检测与置信度协议，无法仅用这些距离确定几何或语言质量。

### 去掉画面外手点主导的时间段

以真人可见性选择最长双手合格连续区间，即原片第 30–60 帧（零基、含两端）。11 帧进入优化，10 个独立奇数帧有 16 个可关联 MediaPipe 手实例。保持同一搜索预算、同一相机与初态。纯几何和 RGB 反馈的留出像素误差分别为 **14.052 和 13.927 px**，差 **−0.125 px**。RGB 时序距离 **0.07484 → 0.06599**。直接反馈达到同一个 3D 更新、同一留出误差。这是同一录像、事后定义的机制检查，当前数据只能表明结果对可见性区间敏感。

原始结果见 `rgb/comparison.csv`、`rgb/image_bounds.csv`、`rgb/<clip>/loop_cross_scored_endpoints.csv`、`visible_window_comparison.csv`。同目录有真人与渲染成对视频、逐步损失、完整提案及参数、初始/最终动画、入界与失配图。检查点未启用 RGB 原生特征分支。
