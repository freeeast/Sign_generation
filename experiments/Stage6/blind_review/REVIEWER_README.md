# Blind ASL review

Each anonymous sample contains an original reference video and three animated versions of the same signing segment. Play the reference first, then view A, B and C in an order of your choice. Playback speed and camera are matched within a sample. The original video supplies the intended sign motion. Score understandability of each candidate from 1 to 5, where 1 is unintelligible and 5 is clearly understandable. Leave a blank if you cannot judge. Record which candidate best preserves the signing, or a tie, and briefly identify specific visible signs or nonmanual features behind the choice. Flag occlusion, clipping, or unclear mouth and facial cues separately. Use an anonymous reviewer code. Repeat across samples without seeing how candidates were generated. 

`review_form.csv` is blank. There are no reviewer judgments in this package.
