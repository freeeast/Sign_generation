# 共享动作数据

## 档案盘点

数值来自作者发布 ZIP 的完整中央目录。按严格的 poses/片段/逐帧模式计数，UNIX/macOS 辅助条目与目录行分开。核对连续索引的数量、上界与索引矩。ZIP 目录不等价于验证了每个 payload，本轮只为所选 775 段读取并查 CRC、字段、尺寸与有限值。

| 官方 NSA split | 完整序列 | 帧 | 11 字符源录像 ID | 帧数中位数 / P95 / 最大 | 使用 |
|---|---:|---:|---:|---:|---:|
| Train | 30,965 | 5,034,216 | 2,192 | 126 / 425 / 2,579 | 600 段、108,480 帧 |
| Val | 1,724 | 273,119 | 115 | 124 / 395.85 / 1,761 | 75 段、14,031 帧 |
| Test | 2,318 | 375,380 | 149 | 127 / 422.45 / 1,319 | 100 段、21,263 帧 |

Val 均值 158.42 帧，指拟合序列实际载入数量。三个官方列表源录像 ID 交集均为 0。可用原始字段无签者 ID，无法确认签者隔离，也未以图像内容另查不同 ID 的重复录像。训练可读池来自公开 ZIP 的受限前段，共 1,870 个 ≥40 帧的完整片段、1,222 源。后续三部分均确定性地按不同录像优先，当前 775 个片段均为各自唯一源 ID。Stage 9/10 六个项目源全数从模型拟合与预测评估样本排除。窗口只在单段内生成。未发现 775 段里被 CRC 或字段筛掉的样本。

原字段为 root、63 维 body、双手各 45、jaw、shape10、expr10、cam_trans3。公开拟合无每帧时间戳、FPS、焦距、主点、摄像机 crop、眼球旋转或独立人格标识。现配对缓存中四个 Stage 9 录像确认为 24 fps。独立模型按输入隔帧与名义 12 Hz 运行，时长按名义 FPS 换算，未逐个视频核验。运动为 NSA 拟合的伪标签。 [作者数据](https://baltatzisv.github.io/neural-sign-actors/) · [How2Sign 与非商业条款](https://how2sign.github.io/)

## 表征与质量

- 每帧选 13 个上身关节与左右各 15 个手指关节，共 43 个。根、腿、脸与相机保留作参数脚手架，模型不训练这些量。渲染后续的未建模姿势保持在 seed 末帧，常量相机取 seed 中值，体型固定在 seed 中位数。闭环对照继承 Stage 10 固定世界参数。
- 输入真局部旋转矩阵在加入 SMPL-X 手均值后构建，网络用其前两列的连续 6D 和相邻相对旋转对数。预处理使用 SciPy SO(3) Log；重放用 Exp 后乘而非世界轴角相减，导出时扣回同一个手均值。训练增量比例仅用训练集算，每关节统一 xyz 标度。左右分开，腕臂躯干有共享历史上下文。
- 训练片段的 beta 最大跨度中位数 0.1571、P95 0.2705，cam_trans 深度跨度中位数 2.604 个拟合量纲。这些未经物理标定。逐片原帧左手相邻转动 P99 的中位数 43.78°，右手 56.58°，上身 27.03°，下肢 3.90°。464/600 段存在至少一项 >90° 相邻相对转动，合计 3,350 个关节步。这是拟合异常与快速变化的混合；未将其简单全部删除。损失对极值使用稳健惩罚，12 Hz 仍有混叠和细节损失风险。
- 训练数据按全片索引、窗口随机种子、split 清单复现，val/test 固定。用 SO(3) 数值与 frame count 检查边界，6D 恢复最大矩阵差 1.19e−7；三个真实样本与原 SMPL-X FK 逐点最大差 1.79e−7 m。当地验证双手顺序为各自 index, middle, pinky, ring, thumb，转换保留指关节的分组。预览 1–3 给出重建对照。绝对角度阈值目前仅是代理，样本未做全碰撞检查。
