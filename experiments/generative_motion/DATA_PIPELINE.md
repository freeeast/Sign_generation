# 数据管线

官方快照 SHA 校验通过。中央目录的连续正面片段 train 30,965、val 1,724、test 2,318，录像 ID 零交集。分别抽取 600/75/100，当中有 421/59 个训练/验证片段满足 96 帧。数据适配器构造同一片内 48 帧步长的 96 帧窗口，覆盖尾部，禁止跨片。训练使用 1,789 个训练窗口，验证池包含 242 个。24 Hz 为正面 NSA 的原项目约定。缺少片内时间戳的序列按名义帧率处理，带不同 fps 字段的片段被拒绝，本实验未对帧率重采样。

复用已有 NSA 安全数组解析、连续帧号、CRC 和有限值检查。旧清单含根、上身和双手角速度 P99、逐帧大于 90° 的计数、体型跨度和相机变化。生成数据保留根与相机之外的 43 个局部关节，不将拟合的相机位移作为人身运动。体型、根和非活跃肌骨参数在导出时统一成中性，原拟合的快速手指动态不做平滑。身体遮挡、深度估计误差和独立航向需要别的观测。

预处理见 [README](README.md)。训练仅统计训练片段归一化参数。数据模型使用已有 SMPL-X 手均值与 axis-angle 协议，完整几何预览复用已验证的正向运动学。官方 NSA 与 How2Sign 原始包不存入 Git。
