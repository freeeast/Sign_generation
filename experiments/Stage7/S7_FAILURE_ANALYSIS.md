# 主要失败机制

| 机制 | 实测证据 | 可实施的下一步 |
| --- | --- | --- |
| 分支记录混淆了左右手 | 旧图激活的两个手数组都与正式 forward 的右手逐元素相同。显式分支修复使四个新源的候选端点都改变。 | 固定左右手输出数值测试，把专门手部专家和修复后双手 Uni-Sign 分开比。 |
| 观测可行不保证留出几何安全 | Safe 提案过实测限制后，3sZj 的留出腕仍 13.63 → 17.39 px，手型 10.76 → 10.12 px。第 85 帧左腕为 9.67 → 22.34 px。末端重排把更严的保护变成频繁弃权，仍有 DKOz 恶化。 | 比较对几何已收敛的候选池进行置信校准排序、允许弃权的局部修正，用新来源锁定最小效应。 |
| 同一 RTMW 仍感知不同域 | 稳健 RGB 专家距离两段下降，正面留出一个平一个差。中指—腕尺度相差约 5–12 px，同网格材质变化引起约 0.008 的遮罩时序距离变化。 | 将 RGB 用作低频校验，收集真人与网格手部充分可见、帧同步的独立样本，按视角验证。 |
| 掩码修正了观测，却改变了损失取舍 | 人工越界样本的掩码改善 2.46 px，真实裁切校准段单独加掩码反而恶化 6.31 px。置信度更严未改变新源决策。 | 在固定评估覆盖下考虑不可靠观测的“不可指导”区间，用真实遮挡数据检验。 |
| 独立自动语义指标准确性有限 | 同专家留出 NLL 名次所有方法相同，侧视两段不同长度、另一段仅四个关联手。 | 用独立训练的孤立签语专家、近邻负样本和同步双视角检验。 |
