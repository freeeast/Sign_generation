# 自动评价与侧视核验

## 五类结果

1. **优化专家。** 在固定支持上的图距离与提案接收分别记录。可靠 RGB 在两个新源的图距离均下降。几何指标并不随之优于纯几何。
2. **几何。** 正面用优化帧之外的奇数帧 MediaPipe 观测，计入腕、指尖和腕相对指尖。共 725 个可关联手实例。MediaPipe 和优化 RTMW 是不同的检测算法，但 MediaPipe 左右关联用 RTMW，NSA 原始拟合也使用 MediaPipe。因此属于训练目标外的观测核验。
3. **运动合理性。** 40 个主端点的形体参数逐元素相同，且增量局部转角、速度、加速度均满足边界。实测最大的三项分别 16.54°、1.079°/帧和 0.141°/帧²。报告手尖二阶差分及腕—躯干中心线的粗距离。缺绝对解剖限位、网格相交和接触真值。
4. **自动识别证据。** 在未用于主优化损失的奇数帧，运行完整冻结 Uni-Sign mT5。候选以四源真人向量做最近邻检索、以四个英文句子算长度归一化 NLL。真实输入和八个几何/反馈条件均为 **4/4** 正确序列检索、**2/4** 英文正确句排名第一；四个来源上的句子排名均为 4、2、1、1，方法间无排名变化。Reliability 正确句 NLL 均值 3.106，传统几何 3.135，真人 3.020。任务和权重仍与优化专家共享，四句干扰也较远，只能验证配对和响应保留。
5. **语言学正确性。** 当前未验证。没有独立训练的签语翻译模型输出或人类评分，NLL 与识别表示不得据此推断手语正确性。

## pose-evaluation 实际运行

调用官方 `DTWDTAIImplementationDistanceMeasure`（提交 `2769b6f49693dd83e2ee81c09355d787afe775c6`）。将留出真人 MediaPipe 与虚拟投影变换为 `(帧,1,20,2)` 的腕相对手点序列，固定每手全部 21 点在图像内的帧集合。8 个源×手侧单元，保留 7 个方法共 56 分数。按帧数平方根归一化，Reliable vs Robust geometry 的平均 DTW 差 **−0.096**；5 个单元下降、2 个相同、1 个上升。Safe 平均 DTW **−0.138**，但主指标更差，符合相对手型和全局腕的冲突。时间重排与忽略缺帧影响该度量，结果属于几何代理。

## 侧视新证据

只用 HTTP Range 从官方侧视 ZIP 拉取四个精确短片，并验证每个成员。49 和 212 帧的两个源侧视帧数与正面相等，均为 24 fps。其余 ETOZ 和 DKOz 侧视分别为 165 和 195 帧，对应正面 218 和 261 帧，未强行按帧配对。侧视弱透视固定相机只用原 3D 拟合与偶数侧视上身 RTMW 点搜索 yaw 和比例平移。训练拟合误差为 28.9 与 40.7 px，视角估计较粗。奇数侧视帧可关联手实例分别 4 和 163，只对第二段汇总。第二段的侧视 MediaPipe 误差如下。

| 方法 | 3sZj 侧视留出综合 px |
| --- | ---: |
| 原拟合 | 54.41 |
| Geometry-only | 59.55 |
| Stage 6 | 59.59 |
| Robust geometry、Factor、Reliable | 60.25 |
| Safe | 57.03 |

这段的传统几何从正面改善，却比原拟合侧视高 5.14 px。Safe 相对鲁棒几何侧视更低、正面更高。由于侧视代理相机、潜在子帧同步误差和 MediaPipe 关联偏差，该对照是域外一致性诊断，不是 3D 真值或物理唯一解。
