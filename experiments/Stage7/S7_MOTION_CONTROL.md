# 扩展动作控制器

旧控制器每个手指、腕、手臂组使用两个全片时间窗。扩展版每组再加一个接近片段后半段的平滑局部窗，并去掉其在原两窗上的分量。旋转轴、公共初态、SMPL-X 形体和物理参数一致。本实验只用鲁棒几何损失。两臂都是 24 个提案。第一轮六个共享维度，第二轮旧控制器再次搜索六维，扩展版搜索三个新增维度和三个共享维度，因此比较的是相同算力下的**可用动作空间及搜索调度**。

| 源录像 | 合成受扰初态，9D 减 6D | 原拟合初态，9D 减 6D |
| --- | ---: | ---: |
| 33jxe | −0.497 px | −0.595 px |
| 3sZj | −0.289 px | +0.472 px |
| ETOZ | +0.608 px | 0.000 px |
| DKOz | −0.352 px | +0.122 px |
| 四源均值 | **−0.133 px** | **约 0.000 px** |

受扰初态三段受益，幅度小。原拟合初态只一段改善，一段持平。3sZj 受扰初态的 9D 平均几何误差更低，但其优化损失变差 0.199，留出腕低 2.31 px、手型高 0.99 px。ETOZ 的 9D 搜索损失和留出误差均恶化。改变维度会改变有限预算下到达的候选集合，当前无法归因给容量或搜索单项。保留六维作为主实验空间；后续需要已知局部错误和更丰富的轨迹监督才能检验共享控制器。

本实验未训练共享模型。详见 [逐源指标](motion_control.csv) 与 `controller/`。
