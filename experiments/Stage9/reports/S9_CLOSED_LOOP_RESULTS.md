## 实际进展

三个主演示粗起点上，联合专家闭环的局部扰动均被实际写入 SMPL-X。3sZj 的直接响应从 **.2793 → .1276 → .0936 → .0931**（提案 0、7、20、36），专家联合接受 **17/36** 项（其一是时序稳定化），显著改善运动几何和手形变化量相对自身粗起点。最终保存 3D 检查点和连续可回放系数。短片、焦点片、长片腕局部指尖 P95 为 **36.74、68.19、70.33 mm**，各超过 Stage 8 C3 的 **15.97、21.19、22.24 mm**。焦点逐指都出现可测的关节运动，去静态偏置的留出二维腕相对动态误差由 **31.98 降至 23.36 px**，比 C3 的 **32.18 px** 小；同顺序纯几何进一步达到 **21.63 px**。实测改进以指尖轨迹为依据，深度和指尖接触尚未得到充分约束。

A 与 C 的主版联合法大多只接受很少更新。以焦点 A/C 为例，35 次优化提案各有 **34 次**触发旋转/增量保护。给临界关节施加初态余量遮罩后，A 的直接距离 **.0655→.0548**、正面误差降为 **10.41 px**，C 的 **.1085→.0853**、正面降为 **16.46 px**。同样余量遮罩纯几何可分别到 **8.38 和 13.86 px**。三段 A/C 因此保留同遮罩几何对照；该诊断减轻了更新卡死，也暴露降低响应与改进几何的冲突。焦点 B 的空间、时序、多尺度、组合分别达到组合量度 **.1663 / .1567 / .1604 / .1581**（正面 **18.94 / 20.14 / 20.46 / 19.99 px**），样本只支持局部诊断。

## RGB 与侧视

RGB 将真实采样帧与实际网格重新送入同一 RTMW，再测同一 Uni-Sign 双手图。主三段 B 的 RGB 响应，粗起点 → 同顺序纯几何 → 联合专家，分别为 **.0995 → .0754 → .0516**、**.2337 → .0996 → .0915**、**.2643 → .1216 → .0925**，每段 13–14 帧，记录的支持率 100%。表里 RGB 和直接都面向该抽样的真人检测，直接主实验的采样更密。完整 24 Hz 的 RGB 用于原始/修正抖动对照与画面验证。阶段 A/C 和第四段端点在原始 CSV 中，改善有特例。RGB 结果依赖虚拟外观及 2D 专家。

焦点另有真人同步侧视。163 个留出手帧的弱透视相机使用 NSA 上肢锚点做粗校准，锚点误差 **40.7 px**。联合专家与同顺序纯几何的侧视综合分别 **61.65 / 61.01 px**，联合专家腕较准（**62.28 / 64.87**），腕相对手形较差（**42.50 / 38.62**）。因此保留侧视为深度诊断。

## 可复现失败

- 焦点 3.75 秒处，真人左手弯曲、拇指靠近，联合 avatar 的手指张得更开。平均拇食间距变幅 **138.62 mm** 高于 NSA **107.51 mm**。更有表达力也允许过度展指；查看[同一时刻手部特写](../STAGE9_VISUAL_DEMONSTRATION/failure_focus_090.png)。
- 层级最后十步的专家阶段在主三段 B 仅接受 **3/1/2** 项。焦点另外九个专家试探触及腕锚点。层级守门减小了训练帧漂移，却未保证留出帧泛化。
- 联合组合目标在个别已接受更新可用几何改善换来响应短时反弹，3sZj 整体下降成立。三个 A/C 起点包含已有高频分量，不能用初态或合成恢复替代真实语言评价。
